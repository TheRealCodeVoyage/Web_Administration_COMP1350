# Online Activity 1: Web Stack Basics

*COMP 1350 — Web Administration — distributed during orientation (Week 0), due before Week 1*

## Why This Matters

Before we touch a single server, you need the vocabulary: what a web server actually does, and how the pieces of a "stack" fit together. Week 1's lecture builds directly on top of what you read here.

## Before Class: Read

- [MDN — What is a web server?](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Server-side/First_steps/Introduction) — a short, plain-language explanation of client/server basics
- [MDN — How does the Internet work?](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Networking_basics) — the request/response journey from browser to server and back
- [nginx.org — Beginner's Guide (intro section only)](https://nginx.org/en/docs/beginners_guide.html) — skim just the first two paragraphs; don't worry about the configuration syntax yet

## Come to Class Ready to Answer

1. In your own words, what is a web server? What is the one job every web server does, no matter which software runs it?
2. What is the difference between a "website" and a "web application"? Is this a hard line or a spectrum?
3. Name the three layers people usually mean when they say "web stack" (hint: front end, ??? , ???).
4. What are the three web servers this course covers hands-on, starting next week?
5. Why do you think a course called "Web Administration" spends its first weeks on web *servers* specifically, rather than on writing application code?

## How This Feeds Forward

- These exact questions form the basis of **Quiz 1**, given in Week 1.
- Week 1's lecture will formalize and extend everything above — the request/response lifecycle, the website-vs-app spectrum, and a first look at Apache, Nginx, and IIS.
