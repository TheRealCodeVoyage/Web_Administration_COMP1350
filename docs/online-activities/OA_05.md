# Online Activity 5: SSL/TLS Recap

*COMP 1350 — Web Administration — distributed Week 4, due before Week 5*

## Why This Matters

Your PaaS deployment from Week 4 almost certainly got you free, automatic HTTPS without you doing anything. Week 5 opens up that black box: what's actually happening when a browser shows a padlock icon.

## Before Class: Read

- [Cloudflare Learning Center — What is SSL?](https://www.cloudflare.com/learning/ssl/what-is-ssl/) — short, clear overview
- [Cloudflare Learning Center — What happens in a TLS handshake?](https://www.cloudflare.com/learning/ssl/what-happens-in-a-tls-handshake/) — the step-by-step version
- [Let's Encrypt — How It Works](https://letsencrypt.org/how-it-works/) — one page, explains automated certificate issuance

## Come to Class Ready to Answer

1. What's the actual difference between HTTP and HTTPS — what specifically changes about the traffic between browser and server?
2. What is the difference between symmetric and asymmetric encryption? Which one does a TLS session use for the bulk of the actual data transfer, and why?
3. What is a Certificate Authority, and why does a browser trust a certificate it's never seen before just because a CA signed it?
4. Let's Encrypt issues certificates for free, automatically, and they expire every 90 days (much shorter than the old multi-year paid certificates). Why might a *shorter* expiry actually be a deliberate security choice, not just an inconvenience?

## How This Feeds Forward

- These questions form part of **Quiz 5**, given in Week 5.
- Week 5's lecture and lab have you generate a certificate by hand (to see every step from question 2-3) before contrasting that with Let's Encrypt's automation.
